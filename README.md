# ダンジョン脱出ハクスラ（試遊版）

1〜4人用ダンジョン探索ボードゲームを、ブラウザで試遊するための版です。1台の端末を回して遊ぶ（ホットシート）形です。ビルド不要の静的HTML/JSなので、GitHub Pages でそのまま公開できます。

## 遊び方

- `index.html` をブラウザで開くか、公開URLにアクセスします。
- 人数と各プレイヤーのジョブ（戦士＝戦闘職 / 盗賊＝探索職）を選んで「冒険を始める」。
- ルールは画面右上の「📖 ルール」で確認できます。
- 進行は自動保存されます（同じブラウザで「続きから」）。

## 今回の範囲（v0.1）

- 盤面は第1〜3層（内側が第1層、外側の第3層に出口）
- ジョブ2種：戦士（第3層ボス撃破で脱出）、盗賊（SPトレジャー2つで脱出）
- 固定成長＋レベルアップ時のPSドラフト（Lv3・5・7はレア1枚入り、最低レベルの人は1枚多く引く）
- 使い捨てAS（最大3枚）、エクストラAP、Lv5からの必殺技
- 群れモンスターと全体攻撃、罠、鍵付き宝箱、ボス

## バランス調整のしかた

数値やカードはすべて `data.js` にまとまっています。HP・ATK・AP、成長表、モンスターの強さ、カードの枚数、必要経験値などを書き換えて保存すれば反映されます。

試遊のときは、ゲーム終了画面に出る「ジョブごとの脱出までの手番数」を記録しておくと、方向性提案の「脱出までのターン数をジョブごとに測る」に使えます。
